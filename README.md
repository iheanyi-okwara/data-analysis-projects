# Featured Projects

## 1. Horizon Health Network — Bed Demand & Workforce Analytics

A healthcare analytics case study examining **patient demand, bed capacity, occupancy and workforce performance across a 37-hospital network**.

The project integrates admissions, bed inventory and staffing data into a structured analytical model and Power BI reporting solution.

### Key Results

- **278** average admissions per day
- **4 days** average length of stay
- **86.2%** average bed occupancy
- **544** average available beds
- **86.2%** actual-to-planned staffing ratio
- **46.7%** safe staffing compliance
- **414** average daily staffing gap

## 2. NorthBridge Health Services — Ticket & SLA Optimisation

An operational analytics project examining **service tickets, SLA performance, backlog, response times, escalations and agent performance**.

The analysis was designed to identify service-delivery bottlenecks and improve visibility into unresolved tickets and SLA risk.

### Key Results

- **3,500** total tickets analysed
- **1,317** resolved tickets
- **2,183** open tickets
- **754** SLA breaches
- **21.5%** SLA breach rate
- **37.6%** resolution rate
- **5.06 hours** average first response
- **40.86 hours** average resolution time
- **464** escalated tickets

### Tools

`SQL` `Power BI` `Excel` `Data Modelling` `KPI Analysis`
